# sevavoice-hindi

हिंदी वॉइस एजेंट — "Build with Agora" हैकाथॉन, ट्रैक: **Voice AI for Bharat: Speak Your Language**

सेवा वॉइस एक हिंदी वॉइस एजेंट है जो नागरिकों को सेवा अपॉइंटमेंट बुक करने में मदद करता है। इसमें Agora Conversational AI (सत्र/टोकन प्रबंधन) और Murf AI Falcon TTS (हिंदी भाषण संश्लेषण) का एकीकरण है।

## प्रोजेक्ट संरचना

```
sevavoice-hindi/
├── config.py          #環境 चर से सेटिंग्स और गुप्त कुंजियाँ
├── tools.py           # एजेंटिक वर्कफ़्लो उपकरण (नागरिक संदर्भ, स्लॉट जाँच, बुकिंग)
├── agent_service.py   # Agora + Murf ऑर्केस्ट्रेशन परत
├── main.py            # FastAPI बैकएंड
├── .env.example       # पर्यावरण चर टेम्पलेट
├── requirements.txt   # पायथन निर्भरताएँ
├── test_workflow.py   # उपकरणों का परीक्षण स्क्रिप्ट
└── README.md          # यह फ़ाइल
```

## स्टेज अप (सेटअप)

### 1. रिपॉज़िटरी क्लोन करें / फ़ोल्डर खोलें

```bash
cd sevavoice-hindi
```

### 2. वर्चुअल वातावरण बनाएँ और सक्रिय करें

```bash
python -m venv .venv
# विंडोज़ पर:
.venv\Scripts\activate
# मैक / लिनक्स पर:
source .venv/bin/activate
```

### 3. निर्भरताएँ स्थापित करें

```bash
pip install -r requirements.txt
```

### 4. 환경 चर कॉन्फ़िगर करें

`.env.example` को `.env` की कॉपी बनाएँ और अपने वास्तविक API कुंजियाँ भरें:

```bash
copy .env.example .env    # विंडोज़ पर
# या
cp .env.example .env      # मैक / लिनक्स पर
```

फिर `.env` खोलें और निम्नलिखित भरें:
- `AGORA_APP_ID`, `AGORA_APP_CERTIFICATE`, `AGORA_CUSTOMER_ID`, `AGORA_CUSTOMER_SECRET` — Agora कंसोल से
- `MURF_API_KEY` — Murf AI डैशबोर्ड से
- `MURF_VOICE_ID` — हिंदी वॉइस आईडी (उदाहरण: `hi-IN-female-1`)

> सभी गुप्त जानकारी सर्वर पर ही रहती है और कभी क्लाइंट को उजागर नहीं की जाती।

## सर्वर चलाएँ

```bash
python main.py
```

सर्वर `http://localhost:8000` पर चलेगा। API दस्तावेज़ `http://localhost:8000/docs` पर उपलब्ध हैं।

## API एंडपॉइंट्स

| एंडपॉइंट | विधि | विवरण |
|-----------|-------|---------|
| `/` | GET | स्वास्थ्य जाँच (हिंदी संदेश) |
| `/session/start` | POST | Agora वार्तालाप सत्र प्रारंभ करें |
| `/session/stop` | POST | सत्र समाप्त करें (`session_id` क्वेरी पैरामीटर) |
| `/tts` | POST | हिंदी टेक्स्ट को बोली में बदलें (Murf Falcon) |
| `/lookup` | POST | नागरिक संदर्भ खोजें (`phone`) |
| `/slots` | POST | सेवा स्लॉट जाँचें (`date`, YYYY-MM-DD) |
| `/book` | POST | स्लॉट बुक करें (`phone`, `date`, `time`, `user_confirmed`) |

### उदाहरण अनुरोध

नागरिक संदर्भ खोजना:

```bash
curl -X POST http://localhost:8000/lookup \
  -H "Content-Type: application/json" \
  -d '{"phone": "+919876543210"}'
```

उत्तर (हिंदी में):

```json
{
  "phone": "+919876543210",
  "summary": "नमस्ते राम शर्मा जी, आपका पिछला रिकॉर्ड मिल गया है। अंतिम सेवा: बिजली कनेक्शन, अंतिम संपर्क: 2024-01-15. टिप्पणी: पिछली बार बिजली कनेक्शन की समस्या दर्ज की गई थी।",
  "language": "hi-IN"
}
```

स्लॉट बुक करना (पुष्टि आवश्यक):

पहले बिना पुष्टि के:

```bash
curl -X POST http://localhost:8000/book \
  -H "Content-Type: application/json" \
  -d '{"phone": "+919876543210", "date": "2024-02-20", "time": "10:00", "user_confirmed": false}'
```

उत्तर:

```json
{
  "result": "कृपया पुष्टि करें: क्या आप 2024-02-20 पर 10:00 का स्लॉट बुक करना चाहते हैं? पुष्टि के लिए user_confirmed=true के साथ अनुरोध भेजें।",
  "language": "hi-IN"
}
```

फिर पुष्टि के साथ:

```bash
curl -X POST http://localhost:8000/book \
  -H "Content-Type: application/json" \
  -d '{"phone": "+919876543210", "date": "2024-02-20", "time": "10:00", "user_confirmed": true}'
```

उत्तर:

```json
{
  "result": "आपकी बुकिंग सफलतापूर्वक हो गई है! बुकिंग संदर्भ संख्या: SV... तारीख: 2024-02-20, समय: 10:00. कृपया इस संदर्भ संख्या को सुरक्षित रखें। धन्यवाद!",
  "language": "hi-IN"
}
```

## स्थानीय परीक्षण (नेटवर्क/API कुंजी के बिना)

उपकरणों को सीधे परीक्षण करने के लिए:

```bash
python test_workflow.py
```

यह निम्नलिखित सत्यापित करता है:
- मौजूदा नागरिक का संदर्भ खोजना (हिंदी सारांश)
- अज्ञात नागरिक के लिए विनम्र हिंदी त्रुटि
- सेवा स्लॉट जाँचना और पूर्णता पर हिंदी सुझाव
- बिना पुष्टि के बुकिंग प्रयास (पुष्टि संकेत लौटाता है, स्थिति नहीं बदलता)
- पुष्टि के साथ बुकिंग (बुकिंग संदर्भ संख्या और हिंदी सारांश लौटाता है)
